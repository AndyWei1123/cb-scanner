📊 可轉債策略儀表板 — WordPress 部署指南

這份指南說明如何將 cb_scanner.py 產生的 cb_dashboard.html 嵌入您的 WordPress 網站。

🗂 檔案說明

檔案說明
cb_scanner.py主程式：抓取資料、計算訊號、產生 HTML
cb_dashboard.html輸出的靜態儀表板（每次執行後更新）
requirements.txtPython 套件需求
wp_embed.html本說明文件

⚙ 安裝 Python 套件

1 在終端機執行： 
pip install -r requirements.txt

▶ 執行掃描並產生儀表板

2 執行主程式（每次想更新資料時執行）： 
python cb_scanner.py
執行完成後，會產生 cb_dashboard.html，用瀏覽器直接開啟可預覽。

🌐 嵌入 WordPress 的三種方式

方法 A：上傳 HTML 並用 iFrame 嵌入（推薦）

1 安裝 WordPress 外掛 WP File Manager 或使用主機的 cPanel/FTP， 將 cb_dashboard.html 上傳到：
/wp-content/uploads/cb_dashboard.html
2 在 WordPress 頁面編輯器中，新增「自訂 HTML」區塊，貼上： 
<iframe
  src="https://你的網域.com/wp-content/uploads/cb_dashboard.html"
  width="100%"
  height="900"
  style="border:none; border-radius:8px;"
  scrolling="auto">
</iframe>
💡 如果頁面太高/太矮，調整 height 的數值即可。

方法 B：直接貼 HTML 內容（適合小型網站）

1 安裝外掛 WPCode Lite（原 Insert Headers and Footers）。
2 開啟 cb_dashboard.html，全選並複製內容。
3 在 WordPress 編輯器新增「自訂 HTML」區塊，貼上完整 HTML。
⚠ 部分 WordPress 主題或安全外掛（如 Wordfence）可能會過濾內嵌 HTML， 遇到此問題建議使用方法 A（iFrame）。

方法 C：搭配 cron 自動排程更新（進階）

如果您的網站主機或 VPS 支援 Python，可設定 cron job 每天自動執行：

# 每個交易日下午 4:30 更新（台灣時區）
30 16 * * 1-5 /usr/bin/python3 /path/to/cb_scanner.py
💡 Mac/Linux 用 crontab -e；Windows 用「工作排程器」。

🔧 常見問題

問題解法
thefew.tw 資料抓不到 程式會自動退回 TWSE / TPEx，或使用示範資料。可在 cb_scanner.py 頂端的 get_demo_cb_data() 手動填入您的可轉債清單。
融券資料顯示「─」 TWSE 融券 API 只在盤後更新。請在收盤後（下午 4 點後）執行程式。
股價為 0 或空白 yfinance 需連網。確認 stock_code 格式正確（如 2330，勿加 .TW）。
上櫃股票找不到 程式已自動嘗試 .TW 與 .TWO 兩種後綴。

📋 自訂可轉債清單（手動模式）

若自動抓取失敗，可在 cb_scanner.py 的 get_demo_cb_data() 中手動維護清單：

def get_demo_cb_data():
    return pd.DataFrame([
        {
          'cb_code': '91611',         # 可轉債代碼
          'cb_name': '儒鴻一',        # 可轉債名稱
          'stock_code': '1476',       # 標的股票代碼
          'stock_name': '儒鴻',       # 股票名稱
          'conversion_price': 285.0,  # 轉換價格
          'cb_price': 102.5,          # 可轉債現價
          'premium_rate': 2.5,        # 溢價率 (%)
          'issue_price': 100,         # 發行價格
          'maturity_date': '2027-06-30',
        },
        # 繼續新增...
    ])

本工具僅供學習與研究參考，不構成任何投資建議。使用者需自行評估風險。
